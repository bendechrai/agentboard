# Tasks

This change restates `board-cli` "Command surface" and "MCP server",
which `add-claim-leases` and `add-harness-integration` also restate (see
design.md, "Overlap with in-flight changes"); whichever change is archived
later re-syncs both requirements with the main spec first, keeping the
other changes' additions. `add-harness-integration` also edits
`src/board/init.ts` and the `init` registry entry: the second group to land
there rebases onto the first and keeps both sets of flags. This change does
not touch "Exit codes".

Every group is delivered by a test author, an implementer and a reviewer in
turn (see CONTRIBUTING.md), on one branch per group named
`<area>/<group-slug>` and cut from `origin/staging`; the test author's first
commit defines the group's exported API as stubs. Verification for every
task includes `make check` and `make check-floor` passing with coverage at
or above 90 percent. Groups 3 and 5 are concurrency-critical (they move
refs that are the only copy of board history, and race other clones): the
orchestrator runs a second reviewer on the strongest model. Groups run in
order, except that group 4 may run in parallel with group 3. Tests that
need git 2.32 or later skip with a stated reason on an older git; tests
that simulate an older git use a `git` shim on `PATH` that reports another
version and delegates to the real one. Tests use temporary repositories and
bare remotes on the local file system, never the network.
